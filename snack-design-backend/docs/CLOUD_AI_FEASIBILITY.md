# 云端AI查询可行性：豆包 / 火山方舟

## 用户诉求与结论

用户不希望在本机部署大模型，不接受用本机Ollama承担推理算力。需要Java后端调用云端AI，像豆包问答一样检索、总结，再把结构化结果与来源保存并返回小程序。

结论：**有官方云端API，可以实现；但不能把它说成开源永久免费查询API。** 豆包App、豆包助手API、模型推理、豆包搜索是不同产品/计费项。模型开源也不意味着第三方托管的推理或搜索免费。

本轮只查阅公开官方文档，未创建账号、开通服务或发起计费调用。未获得用户账单权限，不能确认该账号实际剩余额度。

## 方案A：豆包助手API

官方描述为与豆包同源的企业级API，通过Responses API提供chat、deep_chat、ai_search、reasoning_search能力。[1]

- 接口：`https://ark.cn-beijing.volces.com/api/v3/responses`。
- 云端执行，无需本机大模型。
- 联网模式使用 `doubao_app` 工具的 `ai_search` 或 `reasoning_search`。
- 文档当前标注beta，需要申请测试资格、开通组件、配置API Key。
- 测试期间cURL示例还需 `ark-beta-doubao-app: true` 请求头。
- 不等同于免费豆包App，也不表示与豆包官方联合出品。

官方计费页本轮显示：[2]

| 功能 | 刊例价 |
|---|---|
| 日常沟通 | 0.1元/次 |
| 深度沟通 | 0.2元/次 |
| 联网搜索 | 0.2元/次 |
| 边想边搜 | 0.5元/次 |

该产品按次后付费，所涉底层模型调用不单独计费，但需开通相应模型服务。价格页更新时间2026-04-20，实际以账号控制台及当前订购条款为准，不能把报价当成任何账号的承诺价格。

不宜作为“保证免费且人人立即可调用”的默认接入。

## 方案B：豆包模型 + 豆包搜索Custom版

官方联网搜索文档支持Responses、Chat Completions与Messages协议。[3]

- Responses接口同上；工具配置 `{"type":"web_search","sources":["doubao"]}`。
- Chat接口为 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`；`web_search_options:{}`启用搜索准入判定，由模型决定实际是否搜索。
- 要在方舟控制台开通相应搜索组件。
- Responses返回 `web_search_call` 与引用注解；Chat返回 `message.annotations`、`usage.tool_usage.web_search`，适合记录实际是否搜索及出处。
- 不能只根据模型正文里的网址认定已检索。项目现有白名单来源、摘录、用量与条件性食用建议保护应继续保留。
- 具体可用模型必须以控制台授权和工具支持列表为准，不能使用任意模型名保证可调用。

搜索价格页本轮显示：[4]

- Web搜索Custom按量刊例价 **0.020元/次**。
- 文档另列轻量订阅 **5.9元/月，1000次、每天50次上限**，实际可订购范围及key/接入方式要按控制台核实。
- 搜索订阅与按量key隔离。不能未经确认就认定普通Ark key可直接使用某搜索套餐。
- 模型推理token费用与搜索费用需分开确认；一次模型回答也可能触发多次搜索。

该方案较适合本小程序的定制JSON总结，但不是严格零成本方案，不得在未获用户确认时开通后付费搜索。

## 免费额度到底覆盖什么

方舟免费推理额度页明确写明：[5]

- 免费额度抵扣按token后付费的在线推理费用。
- **不能抵扣插件、知识库等产生的费用**。
- 模型和账户的额度、有效性需在控制台核对。

安心体验模式页进一步说明：[6]

- 符合条件的账号可启用，仅消耗赠送的50万token推理额度，接近额度后暂停服务，避免推理超额收费。
- 模式默认关闭，而且账号有资格条件，不是所有老账号都能开启。
- 即使开启，联网插件等费用仍不能抵扣，不能把安心体验模式当作搜索免费开关。

所以“先用免费云端推理额度”可以作为试用路线，但不能宣传成“官方联网查询永久全免费”。严格0元时，不应静默启用计费搜索，也不能把不联网的模型记忆冒充实时权威查询。

## 建议架构

```text
微信小程序确认原文
  → Java后端（身份/限流/费用开关）
  → 火山方舟云端模型 + 获准启用的搜索
  → 核实实际搜索与来源
  → 用途、益处、风险、条件性用量、食用建议的结构化结果
  → 数据库快照
  → 原有分组解析页
```

Java后端本地开发不等于本机部署大模型：本机仅运行Java与数据库，推理在云端。后续可把Java和数据库一并部署到服务器。小程序不直接保存API密钥。
